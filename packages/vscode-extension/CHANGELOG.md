# Changelog

## 0.1.0

- Added `Ghost Test Catcher: Analyze Current Test File`.
- Added `Ghost Test Catcher: Analyze Changed Test Files`.

- Added configuration for Python path, source paths, execution confirmation, test mode, and max files.
