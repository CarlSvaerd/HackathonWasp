# Review A Test File

Open a Python test file, then click the editor-title shield action or the `Ghost Test: Analyze` status-bar item. The command link below is available when you are already reading this walkthrough.

[Analyze Current Test File](command:ghostTestCatcher.analyzeCurrentTest)

Ghost Test Catcher marks each test with inline diagnostics, CodeLens verdicts, a status-bar summary, and a report panel that shows groundedness, execution status, missing symbols, evidence files, and recommendations. You can also use the Testing panel and run the `Analyze with Ghost Test Catcher` profile against discovered tests.
