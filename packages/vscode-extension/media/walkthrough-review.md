# Review A Test File

Open a Python test file, then run analysis.

[Analyze Current Test File](command:ghostTestCatcher.analyzeCurrentTest)

Ghost Test Catcher marks each test with inline diagnostics, CodeLens verdicts, and a report panel that shows groundedness, execution status, missing symbols, evidence files, and recommendations. You can also use the Testing panel and run the `Analyze with Ghost Test Catcher` profile against discovered tests.
