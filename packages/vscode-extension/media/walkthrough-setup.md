# Set Up Ghost Test Catcher

Start by running setup in a workspace that contains Python tests.

[Run Setup](command:ghostTestCatcher.setup)

Setup finds Python, checks whether `ghost_test_catcher.cli` is importable, writes workspace settings, and opens Doctor. Choose local execution for day-to-day review, static-only mode for cautious first passes, or Docker isolation when your team wants test execution inside a container.
